# Image to Excel Converter (កម្មវិធីបម្លែងរូបភាពទៅជា Excel)

កម្មវិធីឆ្លាតវៃសម្រាប់ស្កេន និងបម្លែង File រូបភាពតារាងពិន្ទុ ឬតារាងទិន្នន័យ (Handwritten / Printed Table) ទៅជា **Microsoft Excel (.xlsx)** ដោយ**រក្សាទម្រង់ដើម 100%** (Headers, កោសិកា Merge, អក្សរខ្មែរ-អង់គ្លេស, ពណ៌ពិន្ទុ, និងកំណត់សម្គាល់ខាងក្រោម)។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

1. **រក្សាទម្រង់ និងរចនាសម្ព័ន្ធដើម (100% Original Template Fidelity)**:
   - Header ក្បាលលើ៖ ឈ្មោះសាលា "សាលាអន្តរជាតិ វេស្ទើន", Registrar's Office, ចំណងជើង "តារាងសម្រង់ពិន្ទុ / Score List"
   - ព័ត៌មានខាងស្ដាំ៖ Teacher Name, Subject, Grade, Quarter, Date
   - បន្ទាត់ក្បាលតារាង 2 ជាន់ (Merged Headers): N°, Name, ឈ្មោះ, Sex/ភេទ, Group/ក្រុម, Conduct, C.P.
   - ជួរពិន្ទុចែកជាក្រុម៖ កិច្ចការផ្ទះ / Homework (1-6), តេស្តខ្លី / Quizzes (1-6), Monthly Test / តេស្តប្រចាំខែ (1-3)
   - បន្ទាត់ព្រំដែន (Thin Borders) គ្រប់ Cell ដូចឯកសារដើមបេះបិទ
   - កំណត់សម្គាល់ Footnotes ជាភាសាខ្មែរ និងអង់គ្លេសនៅខាងក្រោម

2. **ស្គាល់អក្សរខ្មែរ និងលេខសរសេរដៃច្បាស់លាស់ (Khmer Script & Handwriting OCR)**:
   - ប្រើប្រាស់បច្ចេកវិទ្យា Multimodal AI (Gemini 2.5 Flash Vision) ដែលអាចអានស្រៈ ព្យញ្ជនៈ ជើងអក្សរខ្មែរបានត្រឹមត្រូវ
   - អានលេខសរសេរដៃ (100, 95, 90, 80, 50, 0...) យ៉ាងជាក់លាក់

3. **គាំទ្ររូបភាពច្រើនទំព័រ (Multi-Page Merging)**:
   - អាចដាក់រូបភាពទំព័រទី 1 និងទំព័រទី 2 បញ្ចូលគ្នាដើម្បីបង្កើតជាតារាង Excel តែមួយបន្តគ្នា (សិស្សលេខ 1 ដល់ 22+)

4. **ផ្ទាំងពិនិត្យ និងកែសម្រួលមុនទាញយក (Interactive Spreadsheet Grid)**:
   - ផ្ទឹមមើលជាមួយរូបភាពដើម (Split View)
   - អាចកែប្រែទិន្នន័យ លេខពិន្ទុ ឬឈ្មោះផ្ទាល់លើតារាងបាន
   - បន្ថែមជួរថ្មី (Add Row) ឬលុបជួរ (Delete Row)
   - បង្ហាញស្ថិតិសិស្សសរុប ចំនួនសិស្សប្រុស និងសិស្សស្រី

5. **ឯកសារគំរូស្រេច (Pre-Converted Excel Included)**:
   - ឯកសារ `Score_List_1A_Quarter1.xlsx` ត្រូវបានបម្លែងចេញពីរូបភាពគំរូទាំង 2 សន្លឹករបស់អ្នករួចជាស្រេច អាចបើកប្រើប្រាស់បានភ្លាមៗ!

## 🚀 របៀបបើកដំណើរការកម្មវិធី (How to Run)

### 1. បើក Server
នៅក្នុងថតគម្រោង (`d:\Projects Hosting\ImageToExcel`) វាយពាក្យបញ្ជា៖

```powershell
npm start
```

### 2. បើកកម្មវិធីលើ Browser
បើកកម្មវិធីរុករក (Chrome, Edge, Firefox) ហើយចូលទៅកាន់៖
👉 **http://localhost:3000**

---

## 📖 របៀបប្រើប្រាស់ (User Guide)

1. **សាកល្បងភ្លាមៗ**៖ ចុចប៊ូតុង **"មើលទិន្នន័យគំរូ (Load Sample)"** ដើម្បីឃើញទិន្នន័យដែលបានបម្លែងរួចពីរូបភាពទាំង 2 សន្លឹក ហើយចុច **"ទាញយកជា Excel (.xlsx)"** ដើម្បីទាញយកឯកសារ Excel មកកុំព្យូទ័រ។
2. **បម្លែងរូបភាពថ្មី**៖
   - ចុចលើប៊ូតុង **"Gemini API Key"** នៅខាងលើស្តាំ រួចបញ្ចូល API Key របស់អ្នក (អាចយក Free នៅ [Google AI Studio](https://aistudio.google.com/app/apikey))។
   - ទម្លាក់ File រូបភាព (Drag & Drop) ឬចុចជ្រើសរើសរូបភាព។
   - ចុចប៊ូតុង **"ចាប់ផ្ដើមបម្លែង (Convert with AI)"**។
   - ពិនិត្យទិន្នន័យលើតារាង រួចចុច **"ទាញយកជា Excel (.xlsx)"**។
